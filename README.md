# SMSML_Anggara-Budiyanto

Paket tugas akhir kelas Membangun Sistem Machine Learning (Dicoding) - pipeline MLOps untuk prediksi churn pelanggan berdasarkan dataset IBM Telco Customer Churn.

## Isi

- `Membangun_model` - skrip training `modelling.py` (autolog MLflow) dan `modelling_tuning.py` (tuning GridSearchCV dengan manual logging), dataset hasil preprocessing, serta artefak confusion matrix dan feature importance
- `Monitoring dan Logging` - konfigurasi Prometheus, exporter kustom dengan 13 metrik, skrip inference, dan bukti screenshot serving, monitoring, serta alerting Grafana
- `Eksperimen_SML_Anggara-Budiyanto.txt` dan `Workflow-CI.txt` - tautan repo pendukung
